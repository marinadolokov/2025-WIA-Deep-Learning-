Project Title: Classifying braking data and artificial data generation

Short Description: We examine which models and architectures lend themselves the best to detect faulty brakes based on measurement series
of accelerometer data and examine the use of generative AI to augment the dataset. Finally, we examine whether Ensemble models 
are useful in improving the quality of our classifiers.

# 2. Setup & Execution Instructions

First, run `pip install -r requirements.txt`.

The code is structured as notebooks. Put the training data in the data folder and run the notebooks in the code folder.
The gemininn folder is a library and does not contain any notebooks.

Pre-pros and 2d-cnn schould run just fine with standard data provided for first and data generated by pre-pros for second.

The final report containing all of the plots and reports is in the results folder.
